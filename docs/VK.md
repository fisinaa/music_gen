# VK Видео

В панели есть отдельная вкладка VK Видео и кнопка в оформлении готового выпуска.
Загружается сам MP4, название и описание, а не ссылка на YouTube.
Очередь постоянная, отправка потоковая (весь MP4 не загружается в память).
YouTube продолжает работать независимо.

## Обновление

Дождитесь завершения текущей генерации и загрузок:

```bash
systemctl --user stop lofi-web
git -C ~/music_gen pull --ff-only
bash ~/music_gen/scripts/install.sh
bash ~/lofi_auto/connect_vk.sh
systemctl --user start lofi-web
```

## Подключение

Нужен **пользовательский токен VK API** с правом `video`, полученный через
официальную авторизацию собственного/доверенного приложения VK, которому
доступен Video API. `video.save` принимает пользовательский токен (см. официальную
схему VK). Ключ сообщества и токен входа VK ID не являются заменой.
Доступность выдачи нужных прав зависит от типа приложения и разрешений VK;
этот установщик не создаёт приложение и не обходит ограничения выдачи токенов.
Если у вас ещё нет подходящего приложения/токена, сначала проверьте возможность
доступа к Video API в кабинете разработчика https://dev.vk.com/.
Не используйте чужие приложения для получения широких прав на аккаунт.

Запустите `bash ~/lofi_auto/connect_vk.sh` на VM. Скрипт запросит токен скрытым
вводом, затем положительный числовой ID сообщества (без минуса).
Пустой ID означает загрузку на личную страницу пользователя токена.
Для сообщества проверяются права администратора. Перед сохранением показаны
название и ID целевой страницы. Скрипт делает только запросы чтения;
право записи проверяется окончательно первой настоящей загрузкой.

Токен сохраняется в `~/lofi_auto/web_data/vk/token.json` с правами 600
(или в `$LOFI_WEB_DATA/vk/`). Не отправляйте его в чат, Git или скриншоты.
При истечении или отзыве токена повторите подключение. Автообновления токена нет.

## Публикация

1. Откройте «Выпуски → Оформление выпуска».
2. Проверьте название и описание.
3. Нажмите «Сохранить и загрузить в VK» и проверьте целевую страницу.
4. Во вкладке VK Видео смотрите состояние и ссылку.

В первой версии запрашивается открытый доступ к видео. В закрытом сообществе
доступ дополнительно ограничивается самим сообществом. Пост на стене не создаётся.
Обложку VK выбирает из видеоряда; свою можно поставить вручную в VK.
Завершение отправки означает «Передано VK», а не завершение обработки/модерации.
Прогресс — отправленные байты, не подтверждённая готовность видео.

Повторное нажатие обычной загрузки не создаёт дубль. «Загрузить заново» создаёт
новое видео с текущими сохранёнными текстами и сохраняет прежнюю историю.
Старое видео автоматически не удаляется. Поменявшийся MP4 требует нового выпуска.

После потери ответа, остановки панели во время отправки или неясного результата
появляется «Проверь результат в VK». Проверь целевую страницу/видео, прежде чем
создавать повтор. Продолжение загрузки с байтового смещения не реализовано;
слепых автоматических повторов изменяющих запросов нет.

## Проверка

Локальные тесты имитируют API: успех, потерю ответа, перезапуск, смену файла,
неверную страницу, дубли, потоковый multipart и скрытие секретов.
Реальный токен и публикация на аккаунте пользователя в среде разработки не проверены.

Источники API:
- https://github.com/VKCOM/vk-api-schema/blob/master/video/methods.json
- https://github.com/VKCOM/vk-php-sdk#53-uploading-video-files
