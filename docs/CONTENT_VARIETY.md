# Новые сцены и прослушивание стилей

В панели «Создать выпуск» доступны пробы Coastal chillout, Sunset lounge и Ambient piano.
Каждая кнопка добавляет отдельную задачу в существующую последовательную очередь:
два независимых трека по 90 секунд, разные случайные seed, аудиомикс на 150 секунд.
Оригиналы сохраняются в «Музыке» со стилем, seed, датой и меткой «Проба».
Поиск понимает `chillout`, `lounge`, `ambient` и `проба`; понравившийся трек можно отметить звездой.
Проба не создаёт видео и не загружается на YouTube.

## Обновление

Дождаться окончания текущего выпуска и приостановить очередь в панели. Затем на VM:

```bash
git -C ~/music_gen pull --ff-only
bash ~/music_gen/scripts/install.sh
systemctl --user restart lofi-web
```

Обновить страницу панели. По очереди нажать три кнопки проб.
Если очередь на паузе, нажать «Продолжить очередь».

## Что сравнить на слух

| Стиль | Звучание пресета | Сцена |
|---|---|---|
| Coastal chillout | 82 BPM, электропиано, гитара, пэды, мягкий ритм | Тихое побережье |
| Sunset lounge | 85 BPM, Rhodes, джазовая гитара, плавный бас, тихие щётки | Вечерняя терраса |
| Ambient piano | 65 BPM, редкое фортепиано, длинные пэды, без ударных | Туманное озеро |

Все три стиля пока экспериментальные. Пресет описывает желаемое звучание;
точное следование промпту подтверждается только прослушиванием результата ACE-Step.

Для каждого стиля прослушать оба оригинала целиком на одинаковой комфортной громкости:
проверить треск, резкие удары, провалы в тишину, вокал, навязчивый повтор,
естественность мелодии. Для ambient дополнительно проверить отсутствие ударных.
Сохранить seed удачного варианта; неудачный трек исключить из выбора.
После этого проверить длинный трек (180–240 секунд) перед сборкой выпуска.
90-секундная проба не гарантирует качество длинной генерации.

## CLI

```bash
cd ~/lofi_auto
./lofi create --name audition_chillout_01 --style chillout --time-of-day coast --audition
./lofi create --name audition_lounge_01 --style lounge --time-of-day terrace --audition
./lofi create --name audition_ambient_01 --style ambient --time-of-day lake --audition
```

CLI-пробы запускать при свободном worker: панель и CLI используют общий lock.
Повтор той же команды возобновляет сохранённый запуск. Для новых seed использовать новое имя.
Режим `--audition` фиксирует 2×90 секунд, 6-секундный crossfade и 150-секундный микс;
это оставляет запас для обрезки тихих краёв без лишних генераций.
Если качественного звука недостаточно, сборка остановится: тишина не дописывается.
Принятые оригиналы сохраняются в библиотеке.

## Сцены

Новые PNG находятся в `lofi_auto/scenes/06_coast.png`, `07_terrace.png`, `08_lake.png`.
Побережье и терраса статичны; на озере медленно меняется лёгкий туман.
Дождь и пар из кафе не накладываются на новые локации.
«Смена суток» по-прежнему использует только пять исходных фонов кафе.
Любую новую сцену можно сочетать с любым музыкальным стилем.
Список файлов фиксирован: посторонний PNG в папке не сдвигает индексы старых сцен.
Промпты генерации фонов сохранены в `SCENE_PROMPTS.md`.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты используют синтетический звук, временную базу и имитацию YouTube.
Они не подтверждают качество музыки и не публикуют видео на реальном канале.
