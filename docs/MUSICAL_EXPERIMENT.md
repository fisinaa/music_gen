# Рабочий вариант и эксперимент с развитием музыки

Исходная версия закреплена в GitHub в ветке `stable/working-2026-10-11`:
`98b0a47e07a36a482cb8591e4340784521deecb4`. Это состояние репозитория с YouTube,
новыми сценами и VK, до эксперимента. Версия, реально установленная на VM,
может отличаться — её сохраняет checkpoint перед установкой.

Экспериментальная ветка: `experiment/musical-development-20261011`.
По умолчанию остаётся профиль `stable`: прежние промпты не переписаны.
LM, шаги, VAE, модель и зависимости в этом эксперименте не меняются.

## Установка на VM

В панели поставить очередь на паузу, дождаться окончания активной генерации,
монтажа и загрузок YouTube/VK. Затем выполнить:

```bash
cd ~/music_gen &&
git fetch origin &&
git switch --detach origin/experiment/musical-development-20261011 &&
python3 scripts/checkpoint.py --destination ~/lofi-checkpoints/working-20261011 &&
LOFI_SKIP_SERVICE_SETUP=1 bash scripts/install.sh &&
systemctl --user restart lofi-web
```

Если указанная папка копии уже существует, скрипт остановится без перезаписи.
Для повторной установки выбрать новое имя копии. Не удалять первую копию.
Файлы в копии сверяются по SHA-256 при восстановлении. Копия содержит локальный
`config.env`, поэтому хранить её на VM, не отправлять в GitHub.
Это копия кода и настроек студии, а не полный образ VM: веса, Python-окружение,
ACE-Step и его VAE-патч остаются существующими и не изменяются.

## Сравнение

Обновить страницу панели. Выбрать знакомый стиль (например Morning jazz), затем
«Сравнить 3 профиля выбранного стиля» и возобновить очередь.
Кнопка использует только выбранный стиль: спокойное настроение, темп по стилю,
две генерации по 90 секунд на профиль и 150-секундный микс на профиль.
Другие поля формы не влияют на сравнение.

| Профиль | Изменение |
|---|---|
| Текущий · контроль | Прежний промпт |
| Мелодия и развитие | Узнаваемая тема, вариации, контрастная середина, возвращение темы |
| Диалог и движение | Вопросы и ответы инструментов, выразительное время вступления, смена плотности |

Пары используют одинаковые два seed и настройки генератора. Seed и полные промпты
сохраняются в `episodes/compare_*/jobs.json`; повтор задачи использует сохранённые
файлы. Это контролируемое сравнение, но не гарантия побитовой воспроизводимости
на разных версиях библиотек/оборудовании. Для ambient сохранено отсутствие ударных.
Все задачи выполняются последовательно, batch=1, 8 steps. Публикация не запускается.

Прослушивать оригиналы в «Музыке»: сравнивать одинаковые seed, примерно на одной
воспринимаемой громкости. В библиотеке показан профиль, доступны поиск по
`melodic`, `dialogue`, `stable`, избранное и исключение.
Оценить узнаваемость темы, однообразие, развитие, мягкость ритма, артефакты.
Затем проверить лучший профиль на 180–240 секундах. Длинные выпуски можно создавать
с выбранным профилем из той же формы.

## Возврат

Быстрый возврат звучания: выбрать «Текущий · контроль». Новые обычные выпуски
снова используют прежние промпты. Уже поставленные задачи сохраняют свой профиль:
ненужные ожидающие эксперименты можно отменить.

Полный возврат установленного кода: дождаться конца всех задач и загрузок,
приостановить очередь. Сохранить экспериментальный код для возможного возврата,
затем восстановить рабочую копию:

```bash
python3 ~/music_gen/scripts/checkpoint.py --destination ~/lofi-checkpoints/experiment-20261011 &&
systemctl --user stop lofi-web &&
python3 ~/music_gen/scripts/checkpoint.py --restore ~/lofi-checkpoints/working-20261011 &&
systemctl --user start lofi-web
```

Очередь, БД, авторизация, музыка, готовые выпуски и история загрузок не откатываются.
Перед откатом отменить ожидающие экспериментальные задачи, чтобы старый worker
не исполнил их как обычные задачи. Обновить страницу после перезапуска.
Репозиторий можно отдельно переключить на сохранённую рабочую ветку:
`git -C ~/music_gen switch --detach origin/stable/working-2026-10-11`.

## Следующие эксперименты

Реальная генерация/прослушивание выполняются на VM пользователя.
После сравнения промптов — отдельная проверка совместимости 5Hz LM 0.6B с установленным
ACE-Step и памятью. Установка LM и изменение числа шагов в эту версию не входят,
чтобы результат первого сравнения можно было связать именно с промптом.
