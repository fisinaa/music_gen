# Архив выпусков на Яндекс Диске

После подключения панель автоматически сохраняет готовые выпуски в приватную папку
`/Lofi/<имя выпуска>/<SHA-256 видео>/`: MP4, JPEG-обложку, название, описание и
publication.json. Исходные WAV и промежуточный монтаж не загружаются.

## Подключение на ВМ

Обновите код и установите его в рабочую папку. Не запускайте установку во время генерации.

```bash
cd ~/music_gen
git fetch origin
git switch feature/yandex-episode-archive
git pull --ff-only
LOFI_SKIP_SERVICE_SETUP=1 bash scripts/install.sh
bash ~/lofi_auto/connect_yandex.sh
systemctl --user restart lofi-web
```

Для команды подключения нужен OAuth-токен своего приложения с правами чтения и записи
Яндекс Диска. Создание приложения и получение токена описаны в официальной документации:
https://yandex.ru/dev/disk/rest/ и https://yandex.ru/dev/id/doc/ru/register-api .
Ввод токена скрыт; не вставляйте его в чат, Git или командную строку.
Команда проверяет доступ и сохраняет настройку с правами 0600 в
`$LOFI_WEB_DATA/yandex/config.json` (по умолчанию `~/lofi_auto/web_data/yandex/config.json`).
После успешного подключения включается архивирование и очистка, включая ранее готовые
выпуски. Без подключения автоматическая очистка выключена.

## Условия удаления

Все условия должны выполняться одновременно:

- Все пять файлов архива подтверждены Яндексом: совпадают размер и SHA-256.
- Есть хотя бы одна успешная публикация именно этого видео.
- Все незаменённые попытки публикации в YouTube/VK завершены. Отменённые попытки
  игнорируются; ошибки, ожидание и неоднозначный результат блокируют очистку.
- YouTube подтвердил `uploadStatus=processed`; VK вернул готовое видео с player
  без признака processing. При недоступности проверки очистка откладывается.
- Генератор не держит общую блокировку пайплайна.

После этого удаляются `episode.mp4`, `mix.wav`, каталоги `tracks`, `selected_tracks`
и `work` внутри данного выпуска. Копии его треков в музыкальной библиотеке удаляются
только если их источники принадлежат этому выпуску, треки не избранные и не используются
другими выпусками/задачами. Внешние исходники, общие сцены, модели и база остаются.
Файлы, оставленные самим ACE-Step в его downloads, здесь не очищаются: у них нет
достаточно надёжной привязки к владельцу выпуска.

«Все публикации» означает уже зарегистрированные задачи в очередях панели.
Если нужен выпуск на двух площадках, поставьте обе загрузки в очередь. Более поздняя
загрузка тоже возможна: панель восстановит MP4 из архива автоматически.
Приватная/доступная по ссылке публикация YouTube считается завершённой при успешной
обработке с выбранными пользователем настройками видимости.

## Повторная загрузка и просмотр

Во вкладке выпусков появляются ссылка на приватный архив, результат проверки и
ошибка последней попытки. Публичных ссылок программа не создаёт.
Кнопка скачивания из архива возвращает видео на ВМ и проверяет SHA-256 до подмены
локального файла. Обычная повторная публикация в YouTube/VK также восстанавливает
видео автоматически. Нужен свободный объём под MP4 плюс 512 MiB.
Восстановленная копия остаётся минимум час и не удаляется при активной публикации.
Обложка, описание, параметры и история выпуска остаются локально; исходные дорожки
после очистки восстановить нельзя.

Проверка очереди архива выполняется раз в минуту. При обрыве загрузки сохраняются
локальные файлы; следующая попытка проверяет уже переданные файлы. Неоконченная
загрузка отдельного файла начинается заново (побайтового resume нет). Другой файл
по уже занятому пути не перезаписывается автоматически. Архив — снимок оформления
на момент первой загрузки; последующие изменения текста в панели не меняют архив.

## Отключение

Чтобы прекратить автоматическое архивирование и очистку, остановите панель,
установите `enabled` в `false` в приватном `yandex/config.json` и запустите панель.
Не удаляйте токен, если нужна функция восстановления архивных видео.

## Проверки

Тесты используют имитацию API: успех, несовпадение хеша, потеря архива,
незавершённые публикации, обработка площадкой, восстановление и защита ссылок.
Реальная передача в аккаунт Яндекса проверяется после подключения на ВМ.

## Ручная выгрузка

В карточке готового видео есть кнопка «Выгрузить на Яндекс Диск». Она ставит выпуск
в постоянную фоновую очередь, показывает ожидание, выгрузку, успех или ошибку.
При ошибке доступен повтор. Повторные нажатия не создают параллельных копий.
Запрос сохраняется после перезапуска панели; публикация для архивирования не нужна.
Удаление по-прежнему возможно только после успешных публикаций и проверки архива.
