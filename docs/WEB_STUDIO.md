# Retro Reverie Sounds — веб-студия

Первый рабочий этап: веб-панель, постоянная очередь SQLite, библиотека музыки,
просмотр готовых выпусков, пресеты звучания и выбор времени суток.

## Установка / обновление

Дождитесь окончания текущего выпуска. Если панель уже была установлена,
перед обновлением остановите её: `systemctl --user stop lofi-web`.

```bash
git -C ~/music_gen pull --ff-only
bash ~/music_gen/scripts/install.sh
bash ~/lofi_auto/setup_web.sh
cat ~/lofi_auto/web_data/password
```

Откройте **http://IP-ВАШЕЙ-VM:7861**. Логин **admin**, пароль — из последней команды.
Пароль создаётся один раз и при обновлении сохраняется. API ACE-Step остаётся на 7860.

Панель использует стандартную библиотеку Python, дополнительных pip-пакетов
для самого веб-сервера нет. Монтаж и генерация используют прежнее окружение ACE-Step.
Панель работает как пользовательская служба `lofi-web.service`; закрытие браузера
не прерывает задачу. Для запуска после перезагрузки до входа пользователя включите
пользовательские службы без активной сессии:

```bash
sudo loginctl enable-linger "$USER"
```

Служба по умолчанию слушает `0.0.0.0:7861` и требует пароль. Используйте её в доверенной
локальной сети. Для доступа через Интернет нужен защищённый туннель либо HTTPS-прокси;
HTTP Basic сам по себе не шифрует пароль. Порт напрямую в Интернет не публикуйте.

Для привязки только к localhost добавьте в `~/lofi_auto/config.env`:

```bash
LOFI_WEB_HOST=127.0.0.1
LOFI_WEB_PORT=7861
```

После завершения текущих задач: `systemctl --user restart lofi-web`.

## Что можно делать

### Создать выпуск

- Новый звук или выбранные треки из общей библиотеки.
- Длительность 0.5–180 минут.
- Музыка с видео либо только музыка (готовый сведённый WAV).
- Morning jazz, Lo-fi jazz, Coastal chillout, Sunset lounge, Ambient piano.
- Спокойное, тёплое, мечтательное или задумчивое настроение.
- Смена суток либо одна сцена на весь выпуск: дождливое утро, позднее утро,
  день, закат, дождливый вечер.
- Дополнительно: диапазон длительности треков, BPM, дополнение к промпту,
  перекрытие треков и разрешение видео.

Morning — ранее проверенный музыкальный профиль. Остальные пресеты экспериментальные,
они меняют промпты и темп; качество звука нужно оценить на вашей модели.
Погода соответствует готовому фону: отдельного переключателя «солнечная погода»
для картинки с мокрым окном нет. Локация пока одна — кафе.

Seed случайные и сохраняются в заданиях. Настройки CPU/FP32, 8 steps, batch 1,
LLM off, VAE GPU 128/32 остаются прежними.

### Очередь

Задачи сохраняются в `web_data/queue.sqlite`. Работает один исполнитель, при активном
CLI-конвейере ждёт освобождения его блокировки. Ожидающую задачу можно отменить.
Пауза означает «не начинать следующие выпуски»: текущий выпуск завершится.
Остановка посреди трека через интерфейс намеренно не выполняется.

При ошибке очередь автоматически ставится на паузу. Прочитайте журнал и исправьте
причину. Кнопка повтора требует подтвердить, что старая задача ACE-Step завершилась
или сервер был перезапущен. Затем нажмите «Продолжить очередь».
При аварийном перезапуске панели активная задача получает статус «Прервано»;
неоднозначная генерация не отправляется повторно автоматически.

Сам ACE-Step работает в отдельной службе и может продолжать генерацию после остановки
панели. Прежде чем повторять прерванную задачу, это нужно проверить.

### Музыка

Дата и время создания отображаются в часовом поясе браузера; новые треки идут первыми.
Для старых треков дата восстанавливается из манифеста исходной генерации с проверкой
SHA-256. Если манифеста нет, показывается «Дата файла» (время изменения WAV,
которое может соответствовать импорту), а не выдуманное время генерации.
При повторном импорте сохранённая дата не меняется.

Прослушивание, поиск, избранное и исключение неудачного трека из выбора.
Выбранные треки идут в порядке выбора. «Использовать выбранные» возвращает к форме.
На старте сборки делается отдельная копия выбранных WAV с проверкой контрольных сумм.
Изменение списка избранного позднее не изменяет уже поставленную задачу.

Импорт прежней очереди:

```bash
cd ~/lofi_auto
./lofi collect --tracks ~/lofi_queue/runs/morning_long
```

### Выпуски

Просмотр MP4, прослушивание микса, скачивание результата и треклиста.
Отображаются также старые завершённые выпуски из `~/lofi_auto/episodes`.
Заданный в форме заголовок сохраняется отдельно от технического имени каталога.

## Данные и журналы

| Путь | Содержимое |
| --- | --- |
| `web_data/queue.sqlite` | Очередь, пауза, избранное/исключения |
| `web_data/password` | Пароль администратора, права 600 |
| `web_data/logs/` | Вывод запуска конвейера для каждой задачи |
| `episodes/web_.../` | Результат, задания, выбранные исходники, промежуточные файлы |
| `music/` | Общая библиотека WAV и каталог |

Все эти рабочие данные исключены из Git. При резервном копировании остановите
панель и сохраните каталог `web_data` целиком вместе с музыкой и выпусками.

```bash
systemctl --user status lofi-web
journalctl --user -u lofi-web -n 100
systemctl --user stop lofi-web
systemctl --user start lofi-web
```

Панель + монтаж ограничены 8 CPU и 8 GB RAM; генерация ACE-Step — отдельной
ранее установленной службой. Граница 2 GB свободного диска перед стартом — только
защита от запуска на почти полном диске; она не гарантирует места на длинный выпуск.
Автоматическая очистка диска и оценка будущего размера — последующие этапы.

## Проверки

```bash
~/ACE-Step-1.5/.venv/bin/python -m unittest discover -s ~/music_gen/tests -v
```

Тесты не вызывают модель ACE-Step. Используют временные каталоги и синтетические WAV:
доступ по паролю, валидация ввода, защита путей, Range-запросы, постоянная очередь,
пауза/отмена, один активный исполнитель, восстановление прерванного состояния,
реальный запуск сведения через веб-очередь.

Приватная загрузка на YouTube доступна после [подключения канала](YOUTUBE.md).
Расписание публикаций пока не реализовано.
Обложки и редактируемые тексты выпуска доступны в панели.

## Оформление выпуска

После сборки автоматически создаются `thumbnail.jpg` (1280×720), `title.txt`,
`description.txt` и `publication.json`. Английские тексты собираются из музыкального
пресета, сцены, длительности и фактического треклиста — внешняя LLM не требуется.
Таймкоды обозначают начало трека в миксе с учётом перекрытий; они не гарантируют,
что YouTube выделит их в главы. Обложка использует первый фон выбранного режима.

Во вкладке «Выпуски» нажмите «Оформление выпуска»: здесь можно посмотреть обложку,
отредактировать название и описание и скачать файлы. Для прежних выпусков пакет
создаётся этой же кнопкой без повторного монтажа. Ручные правки сохраняются.
Надпись на обложке определяется пресетом и сценой; изменение названия видео её
не меняет. Ошибка оформления не удаляет готовое видео: повторите через кнопку.
После проверки оформления можно загрузить приватное видео: см. [YouTube](YOUTUBE.md).

Во вкладке YouTube есть «Загрузить заново»: создаёт новое приватное видео с текущим
сохранённым оформлением, сохраняя историю прежней загрузки. Подробнее —
[повторная загрузка](YOUTUBE.md#повторная-загрузка-выпуска).
