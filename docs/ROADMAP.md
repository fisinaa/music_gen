# Развитие

Реализовано: очередь ACE-Step, стабильные случайные имена, общая WAV-папка,
техническая проверка, сведение, пять анимированных сцен, MP4, продолжение монтажа.

Следующие этапы:

1. Проверить 30-минутный выпуск на целевой VM: звук, стыки, видео, расход диска.
2. Добавить профили выпуска: всё утро / полный день / вечер, разные музыкальные стили.
3. Добавить наборы согласованных фонов: квартира, кафе, терраса у моря.
4. Подключить YouTube OAuth и возобновляемую загрузку приватного видео.
5. Хранить ID загрузки и исключать дубликаты после сбоя.
6. После проверки выпусков добавить расписание публикаций и уведомления об ошибках.

YouTube, OAuth, автоматическая генерация новых изображений и расписание сейчас
не реализованы. Не добавляйте OAuth-токены в Git. До подключения публикации
потребуются канал, авторизация владельца и выбранные настройки доступа.
