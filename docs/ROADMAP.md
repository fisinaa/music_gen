# Развитие

Реализовано: очередь ACE-Step, общая библиотека музыки с датами, сведение,
анимированные сцены, MP4, веб-студия, редактируемое оформление выпуска,
OAuth Desktop и постоянная очередь приватных загрузок YouTube.

Следующие этапы:

1. Проверить OAuth и первую настоящую загрузку на канале владельца.
2. Расписание создания выпусков и публикаций после проверки допуска API-проекта.
3. Контроль места на диске, очистка временных файлов, уведомления.
4. Новые согласованные фоны и проверка экспериментальных музыкальных пресетов.

Тесты загрузчика используют симулятор Google; они не подтверждают доступ к каналу,
реальные квоты или качество музыки. Подключение и проверка — `YOUTUBE.md`.
