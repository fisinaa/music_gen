# Происхождение компонентов

- `lofi_auto/`: обвязка, подготовленная для этого проекта.
- `lofi_auto/scenes/`: пять изображений кафе, сгенерированных для проекта;
  анимация дождя, пара и тумана выполняется кодом.
- `patches/vae_gpu_fp32/generate_music_decode.py`: модификация файла ACE-Step 1.5
  из рабочего checkout пользователя. Это сторонний код с локальным изменением;
  его происхождение и условия upstream сохраняются.
- Модели ACE-Step, PyTorch, FFmpeg и Python-зависимости не включены в репозиторий.
  У них отдельные условия использования. Общую новую лицензию на весь набор
  этот репозиторий не назначает.

Не включены: сгенерированные треки и видео, кеш, веса моделей, окружения,
учётные данные YouTube. Они хранятся на рабочей VM.
