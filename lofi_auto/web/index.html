Проверка подключения…

Доступ выбирается перед загрузкой: ограниченный, по ссылке или открытый. Сначала проверь оформление во вкладке «Выпуски». Браузер можно закрыть после добавления загрузки.

Как подключить канал

Создай в Google Cloud проект, включи YouTube Data API v3 и создай OAuth-клиент типа Desktop app. Добавь свой Google-аккаунт в Test users, если приложение в режиме Testing.

Сохрани скачанный JSON на VM как ~/lofi_auto/client_secret.json. Не отправляй его в чат или Git.

Если браузер на другом компьютере, открой там SSH-туннель:

ssh -N -L 8765:127.0.0.1:8765 faa@IP-VM

Затем на VM:

chmod 600 ~/lofi_auto/client_secret.json
bash ~/lofi_auto/connect_youtube.sh

Открой напечатанную ссылку, выбери канал и подтверди его название в терминале. Подробности — docs/YOUTUBE.md в репозитории.
