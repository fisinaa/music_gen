# music_gen — локальная lo-fi студия

ACE-Step → очередь треков → общая музыкальная папка → сведение → видео кафе.
Рабочий профиль: Ubuntu 22.04.5, 18 vCPU, ~48 GB RAM, GTX 1660 SUPER 6 GB.
DiT и текстовый энкодер работают на CPU; VAE временно переносится на GPU в FP32.

## Установка на уже настроенную VM

ACE-Step и проверенный патч VAE уже должны быть установлены. Этот репозиторий
не переустанавливает PyTorch и не заменяет модели.

```bash
cd ~
git clone https://github.com/fisinaa/music_gen.git
bash ~/music_gen/scripts/install.sh
```

Код устанавливается в `~/lofi_auto`. Существующие WAV, выпуски, кеш и `config.env`
сохраняются. Изменяемые старые файлы кода копируются в `~/lofi_auto/backups/`.
Установка не перезапускает работающий ACE-Step.

Собрать уже готовые треки в одну папку со случайными устойчивыми названиями:

```bash
cd ~/lofi_auto
./lofi collect --tracks ~/lofi_queue/runs/morning_long
```

Результат: `~/lofi_auto/music/*.wav`; `catalog.json` хранит имена, seed и промпты.
Повторный запуск не создаёт дубликатов. Служебные исходники очереди сохраняются.

Собрать 30 минут видео из готовой очереди:

```bash
./lofi build --tracks ~/lofi_queue/runs/morning_long --name cafe_day_001 --minutes 30
```

Полный новый выпуск с генерацией треков 180–240 секунд:

```bash
./lofi create --name cafe_day_002 --minutes 30
```

Результат: `~/lofi_auto/episodes/cafe_day_002/episode.mp4`, `mix.wav`, `tracklist.txt`.
Повторите ту же команду для продолжения монтажа; для нового выпуска меняйте имя.
Ошибки/неопределённый исход генерации требуют проверки перед повторной отправкой:
[подробная инструкция](lofi_auto/README.md).

## Веб-панель

После установки кода:

```bash
bash ~/lofi_auto/setup_web.sh
cat ~/lofi_auto/web_data/password
```

Откройте `http://IP-ВАШЕЙ-VM:7861`, логин `admin`, пароль из файла.
Панель: создание выпуска, постоянная очередь, библиотека и просмотр результатов.
Есть пресеты музыки, настроения и времени суток. [Полная инструкция](docs/WEB_STUDIO.md).
Перед обновлением панели дождитесь окончания задачи и остановите `lofi-web`.

## Обновление

Дождитесь завершения текущего задания, затем:

```bash
git -C ~/music_gen pull --ff-only
bash ~/music_gen/scripts/install.sh
```

Для необязательных локальных путей скопируйте
[configs/config.env.example](configs/config.env.example) в `~/lofi_auto/config.env`.
Этот файл не перезаписывается установщиком и не попадает в Git.

## Что находится в репозитории

| Каталог | Содержимое |
| --- | --- |
| `lofi_auto/` | Конвейер, очередь Gradio, библиотека музыки, монтаж и служба ACE-Step |
| `lofi_auto/scenes/` | Пять согласованных сцен кафе: утро → день → закат → вечер |
| `patches/vae_gpu_fp32/` | Проверенный на VM патч, установщик с проверкой хешей и откат |
| `configs/` | Пример локальной конфигурации |
| `examples/` | Задание на 180 секунд и пример длинной очереди |
| `docs/` | Рабочие настройки, восстановление, ограничения и план развития |

## Проверено

- На целевой VM: генерация длинных треков; VAE GPU FP32 ~22 секунды с переносами,
  пик выделения GPU ~1.98 GB вместо CPU-декодирования ~9:37 для того же теста.
- Локально: 30-секундный монтаж с пятью сценами, полное декодирование MP4,
  нормализация до -18 LUFS, продолжение без пересборки, отбраковка тишины,
  стабильные имена и отсутствие дубликатов в музыкальной папке.
- Пользователь подтвердил успешный 10-минутный монтаж на целевой VM.
- Веб-очередь проверена локально с реальным сведением синтетических WAV;
  запуск модели из веб-панели на целевой VM нужно проверить после установки.

## Границы текущей версии

Анимации используют короткие повторяющиеся петли готовых изображений.
Загрузка на YouTube с выбором доступа из панели доступна после подключения канала: [инструкция](docs/YOUTUBE.md).
Новые фоны и публикация по расписанию пока не реализованы.
Пресеты музыки и времени суток доступны в веб-панели и CLI.
Технические проверки не оценивают художественное качество музыки.
