# DiT CPU + VAE CUDA FP32

Патч по рабочему `generate_music_decode.py` пользователя. Новый путь включается
`ACESTEP_VAE_ON_GPU=1` и рассчитан на `--device cpu`. VAE временно переносится на
CUDA в FP32, autocast отключён; чанки 128, перекрытие 32. Готовое аудио сразу в RAM.
Модель возвращается на CPU даже при ошибке. NaN/Inf отклоняются, OOM передаётся
вызывающему коду без скрытого повторного CPU-декодирования.

На целевой GTX 1660 SUPER проверено 05.10.2026: около 22 секунд с переносами,
пик выделения GPU 1.98 GB. На той же задаче CPU VAE занимал около 9:37.

После остановки ACE-Step, если патч ещё не установлен:

```bash
~/ACE-Step-1.5/.venv/bin/python ~/music_gen/patches/vae_gpu_fp32/install.py
```

Установщик проверяет исходник и AST вспомогательного декодера, сохраняет резервную
копию. На несовместимом checkout завершится с STOP. Не обходите проверку.
На уже пропатченном файле сообщает Already installed.

Для обычной работы используйте службу из `lofi_auto/setup.sh`.
`start_hybrid.sh` сохранён как отдельная ранее проверенная команда:

```bash
bash ~/music_gen/patches/vae_gpu_fp32/start_hybrid.sh
```

Не запускайте её одновременно со службой или старым сервером.
Для диагностического CPU-пути: `ACESTEP_VAE_ON_GPU=0 bash .../start_hybrid.sh`.
Полный откат — вернуть резервную копию после остановки сервера.
